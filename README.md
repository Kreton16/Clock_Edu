# VR Time-Telling Educational App for Children

An interactive Virtual Reality application built in Unity designed to help children learn how to read both analog and digital clocks in an engaging, gamified environment.

## Overview
Learning to tell time can be abstract for young learners. This VR experience bridges the gap by allowing children to physically interact with clock hands in 3D space and immediately see the corresponding changes on a digital display, reinforced by interactive tasks.

## Key Features
- **Interactive Analog & Digital Sync:** Users can grab and rotate the hour and minute hands in VR, dynamically updating the digital clock readout (and vice versa).
- **Guided Learning Tasks:** Mini-challenges asking the user to set specific times with immediate visual/audio feedback.
- **Child-Friendly VR UX:** Simplified controls, clear visual cues, and comfortable spatial scale tailored for younger users.

## Tech Stack
- **Engine:** Unity (C#)
- **VR Framework:** XR Interaction Toolkit

## 🚀 How to Run
1. Clone the repository: `git clone (https://github.com/Kreton16/Clock_Edu.git)`
2. Open the project in Unity Hub (Unity version `6000.6.7f1`).
3. Load the main scene from `Assets/Scenes/...` and run in VR mode or using the XR Device Simulator.
